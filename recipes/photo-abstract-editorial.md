# Photo Abstract Editorial

## 一句话结果

保留完整原片，并从照片的空间、色彩和明暗关系中生成一块抽象记忆面板。

| 字段 | 内容 |
|---|---|
| 适用场景 | 看展、建筑、旅行空间和具有鲜明色彩关系的照片 |
| 输入 | 一张照片 |
| 输出 | 原片、抽象记忆面板和英文标题组成的编辑设计 |
| 核心约束 | 不重绘照片区域；抽象部分只使用输入照片中存在的关系 |
| 当前验证 | 已核实项目与包含原片区域的结果案例 |
