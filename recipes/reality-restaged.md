# Reality Restaged

## 一句话结果

保留纪实照片中的真实人物与关系，只在周围世界加入一个不可能元素。

| 适用场景 | 旅行、街头和人物纪实照片 |
| 输入 | 一张纪实照片 |
| 输出 | 保留真实记忆关系的超现实场景 |
| 核心原则 | `Reality first. Surrealism second.` |
| 核心约束 | 一张作品只加入一个不可能元素 |
