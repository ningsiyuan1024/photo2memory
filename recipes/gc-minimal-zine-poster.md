# GC Minimal Zine Poster

## 一句话结果

把一张照片、一个主题或一种情绪，压缩成留白充足的极简 Zine 海报。

| 字段 | 内容 |
|---|---|
| 适用场景 | 旅行代表画面、展览印象、地点或情绪纪念 |
| 输入 | 照片、主题、一句话、文章想法、物体或情绪 |
| 输出 | 极简 Zine 海报 |
| 视觉特征 | 大面积留白、小型视觉主体、色彩锚点、复印或旧纸质感 |
| 当前调用名 | `gc-minimal-zine-poster-v0-3` |
| 当前验证 | 已核实项目与公开作品 `Night Door` |
| 我们的实测 | 计划在 v0.2 加入 |
| 核验日期 | 2026-08-23 |
