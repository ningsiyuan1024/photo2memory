# 照片拓印海报 · Photo Rubbing Poster

把一张照片做成一张 3:4 竖版海报：上半保留现场，下半把同一主体压缩成一个带印刷痕迹的抽象标识。

| 字段 | 内容 |
|---|---|
| 适用场景 | 建筑、器物、街景，尤其是有清楚轮廓、结构节奏或姿态的照片 |
| 输入 | 一张真实照片；有多个主体时，可指定要提炼的那个 |
| 输出 | 一张独立竖版海报；上半真实摄影，下半只保留一个符号 |
| 核心约束 | 3:4 画幅，上下严格各半；不重绘原图主体；符号必须能追溯到照片结构 |
| 使用门槛 | 可上传参考图片并生成/编辑图像的工具；必要时用排版工具拼版 |
| 当前验证 | 已编写；有构图与推导示意，真实照片输入—输出待实测 |
| 记录日期 | 2026-11-20 |

## 和 Photo Abstract Editorial 的区别

[Photo Abstract Editorial](photo-abstract-editorial.md)提炼整张照片的空间、色彩和明暗氛围。本方法优先提炼**一个主体为什么一眼可认出**，再用轮廓、结构关系或姿态做成一个近似品牌标识的图形，不加主标题。

## 来源与案例边界

这是按 Sylan 在 Photo2Memory 的创作需求整理的新增方法，非第三方项目的转载。案例示意是本仓库制作的结构图，不是实拍，也不是生成模型的实测成品。实测时配对记录可公开的原片与成品，并注明工具和哪些部分经过手工拼版。
