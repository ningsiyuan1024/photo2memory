# Starryear Threefold Memory

## 一句话结果

把一张旅行照片重新组织成“所见、事实与余忆”三层结构的纵向记忆三联画。

| 字段 | 内容 |
|---|---|
| 适用场景 | 旅行、看展、城市漫游和具有明确地点感的照片 |
| 输入 | 一张旅行照片 |
| 输出 | 三张横向 16:9 画面纵向拼接的记忆三联画 |
| 上层 | `What I Saw`：从原图提炼颜色、形状、光线和空间节奏 |
| 中层 | `What Happened`：保留未经重绘的原始照片 |
| 下层 | `What Stayed`：将路线、方向、重复和情绪组织成记忆图谱 |
| 当前验证 | 已核实 GitHub 项目、小红书展示与公开案例；尚未由我们实测 |
| License | GitHub API 未识别到明确 License；README 声明原始照片未经许可不可复用 |
| 核验日期 | 2026-08-25 |
