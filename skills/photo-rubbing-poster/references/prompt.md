# 可复制提示词：照片 → 拓印图形

先上传原图，再复制下面整段。若你的工具没法保留原片像素，按 [Skill 工作流](../SKILL.md) 分层生成与拼版。

```text
把我上传的照片制作成一张独立的 3:4 竖版设计海报。最终画布在水平中线严格平分，上、下各占 50%，无跨区元素。上半是真实摄影，下半是从同一主体提炼的一个抽象视觉标识。

上半区：保留原图主体结构、真实质感、自然光影和原有色彩氛围，只进行轻量调色，呈现艺术摄影和独立出版物的质感。允许为适应画幅自然延展背景，不允许拉伸、扭曲、重绘、改变主体或用另一次生成替代原片。

下半区：从原照片中选择最有辨识力的一到三个特征，例如主体轮廓、结构连接、姿态、叙事关系或负空间。删去细枝末节，用几何解构、模块、线条和负空间把主体压缩成一个能独立成立的符号，不描摹完整物象。符号在缩小后依然要让人看出它与原图的联系。

视觉参考：post-digital graphic design、deconstructed Swiss design、generative symbol system、diagrammatic abstraction。几何模块、细线、圆弧、网格、节点、微型符号或编号择需使用，不要求同时出现。用少量不完美应对严整的结构，让精密和手工痕迹并存。下半区只有一个视觉焦点，居中或微偏移，保留大面积留白。不要堆图标，不要做信息图表，不要做主标题；至多使用极小的字母、编号、短句作为档案式索引。

从照片里取一到两个标志性色调，配灰白或暖白。当青绿、蓝、洋红或橙确实来自照片或呼应其色调时，可选一个作为功能色。避免杂乱配色、强霓虹和商业渐变。印刷效果只做轻微：xerox texture、risograph grain、微小套色错位、扫描噪点或纸张纤维。不能靠噪点掩盖线条，也不要把拓印误做成整张照片的滤镜。

输出一张完整海报，不要展示设备样机、边框或多套方案。理想的下半区像艺术机构、建筑事务所或实验厂牌可以独立使用的视觉标识，同时保留这张照片独有的气质。
```
